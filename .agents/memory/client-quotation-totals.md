name: Client quotation totals
description: Client-facing quotation summaries must show VAT-inclusive payable totals alongside HT.
---
Show both HT and TTC in client quotation summaries, with TTC prominent.

**Why:** The user explicitly stated that clients primarily need to know how much they will pay, which is the TTC figure. HT alone is insufficient.

**How to apply:** Use authoritative recorded totals, never infer a blanket VAT rate. If TTC is unavailable, state that rather than substituting HT or guessing.
