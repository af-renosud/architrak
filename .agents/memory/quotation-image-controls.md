---
name: Quotation annotation image controls
description: Keep image sizing simple and consistent with the translated quotation.
---

Quotation annotation images should offer Small, Medium and Large presets, not drag-to-resize handles.

**Why:** The user found annotation photos too large and explicitly requested simple preset choices rather than handles.

**How to apply:** Preserve image proportions and the saved size choice when reopening an annotation and generating the translated PDF. Avoid introducing a more complex resizing interface without a new request.
