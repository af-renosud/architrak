---
name: Inline quotation context
description: Context text and images must remain directly editable in the Translation view.
---

Keep rich context editable directly beneath each translated quotation item. Do not require opening the working quotation editor merely to add context text or images.

**Why:** The user explicitly rejected the read-only preview introduced by the unified editing workflow: context entry is frequent and must remain quick.

**How to apply:** Keep autosave status, recoverable drafts, conflict detection and upload/save approval blocking. Approved packages must be reopened for review before changing client-facing content. Multiple editing surfaces must not clear one another's pending-work indicators.

Closing the working editor must not be blocked by another surface's pending context.

**Why:** That traps the operator away from the context that needs saving or conflict resolution.

**How to apply:** Keep approval guarded, but allow navigation with draft retention. Only the editor's own active update should temporarily prevent dismissal.
